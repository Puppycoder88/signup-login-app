# React Login/Signup Application

A simple React application with Login and Signup pages using `react-router-dom` for navigation.

## Features

- Login page
- Signup page
- Navigation between pages

## Prerequisites

- Node.js (v16+ recommended)
- npm

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Puppycoder88/signup-login-app.git


2.  Go to the project folder:

cd signup-login-app

3. Install dependencies:

npm install


# Running the Application
## Start the development server:
npm start

Open http://localhost:3000 in your browser.
